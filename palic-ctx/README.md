# pctx — PALIC с контекстами активности, блочный конвейер как у HALIC (прототип)

RCT (Y = G + ((U+V)≫2), U = B−G, V = R−G) → блоки по 200 строк (остаток < 101 строки приклеивается к последнему,
как в HALIC) → MED по каждой плоскости → zigzag → символ `s = bit_width(zz)` + (s−1) сырых бит мантиссы.

**Предиктор на плоскость-блок** (как в HALIC, байт в заголовке блока): 0 MED, 1 `(2(a+b)−c)/3`, 2 `(a+b+1)>>1`
(3 `(a+c+1)>>1` — кандидат, выключен). Выбор по минимуму Σ bit_width(zz); `-P mask` для опытов.

**Контекст** — класс активности своей плоскости, `act = |a−c| + |c−b| + |b−d|`, класс = число порогов ≤ act:
Y `1, 3, 10, 18, 35`, U/V `1, 4, 8, 16, 30` (6 классов; пороги подобраны на выборке CLIC 250×1000 px).

**Потоки на блок (PCX3):** символ — сам zigzag-остаток целиком (Y < 256, U/V < 512, без сырой мантиссы); 11 потоков:
класс 0 (плоские места, Σ|g| = 0) общий для Y, U, V; классы 1..5 Y; классы 1..5 хромы, общие для U и V. Все потоки —
FSE Коллета (тот же движок, что у HALIC), одна таблица на поток на блок: байтовый FSE (tableLog 12), если все символы
потока < 256 (как «FSE-256» у HALIC, бит 19), иначе FSE-U16; `-16` — всегда U16. Предсказание идёт через границы
блоков, сбрасывается только статистика.

```
pctx c in.ppm out.pcx [-b rows] [-P mask]     pctx d in.pcx out.ppm     pctx bench [-b rows] [-P mask] a.ppm ...
```
Собирается из корня plt2 вместе с `plt2` (`build/pctx`).

Выбор предиктора: −0.33% на наборе в целом, на шумных до −2.2% (astronaut, camera, coffee); чаще всего выбирается `(a+b)/2`.

Полный алфавит (PCX3) против `bit_width` + сырой мантиссы: −3.2% и декод на 14% быстрее. Высота блока: 100 строк 4.4738,
**200 — 4.4736**, 400 — 4.4802, вся картинка — 4.4907. Белый шум: 25.8 бит/пикс (хрома R−G/B−G 9-битная) — нужен raw-режим.

Байтовый путь FSE для потоков < 256 (все потоки Y и большинство хромы): размер тот же, декод +22%, энкодер +10%.

## PCX4: конвейер HALIC целиком (разбор REA) + наши контексты
17 цветовых режимов на блок (тройки из R, G, B, Y, Co, Cg, D), предиктор на плоскость-блок, FSE 8/16, raw-байты.
`-k 0 -C 1 -I 1` — копия устройства HALIC в нашем формате (одна таблица на плоскость, выбор по Σ|Δx|, независимые блоки).

| 13 картинок + 4000×3000 (Ivy Bridge ISA, 1 поток) | bpp | enc / dec MB/s |
|---|---|---|
| **pctx по умолчанию: контексты, режим по MED-стоимости, предсказание через границы** | **4.4502** | 83 / 160 |
| то же, независимые блоки (`-I 1`) | 4.4779 | 82 / 157 |
| то же, всегда Y,Co,Cg (`-C 0 -I 1`) | 4.5010 | 92 / 159 |
| копия HALIC (`-k 0 -C 1 -I 1`) | 5.0414 | 90 / 222 |

Выбор цветового режима: −0.5%; независимость блоков стоит +0.6%; контексты — −12% к копии HALIC.
