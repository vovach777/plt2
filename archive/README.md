# Архив: альтернативные раскладки потоков PLT2

`plt2_layouts.cpp` — полная версия со всеми раскладками (`-DSPLIT=N`). Финальный `../plt2.cpp` = раскладка 3,
поток байт-в-байт совпадает с `-DSPLIT=3` отсюда. Сборка: `clang++ -O3 -march=native -std=c++17 -pthread -I.. -DSPLIT=N plt2_layouts.cpp`.
Файлы разных раскладок несовместимы (байт 14 заголовка = номер раскладки).

| SPLIT | буферов на полосу | что внутри | кодер | итог |
|---|---|---|---|---|
| 0 | 1 | 6 потоков: 3 RC + 3 bypass | N задач | не лучше 3 |
| 1 | 3 | по компоненте: RC + свой bypass | 3N задач (компоненты отдельно) | паритет по скорости, +8 B/полосу |
| 2 | 4 | 3 чистых RC + 1 bypass без резервирования (кодер сливает списки по пикселям) | 3N | паритет |
| **3** | 1 | **4 потока: 3 RC + общий bypass** | N | **финал** |
| 4 | 1 | 3 RC, bypass = равномерная псевдобуква в RC (второе деление в декодере) | N | −5% на A15/статике, −12…16% на шуме |
| 5 | 1 | 3 RC, bypass = прямые биты LZMA (без деления, по одному биту) | N | −12% декод A15, кодер на шуме вдвое медленнее |

Размер у всех одинаковый (разница — десятки байт на полосу). Шум 1920×1080, `-x -m 0`, enc/dec MB/s:
SPLIT 3 — 54.8 / 54.6, SPLIT 4 — 48.9 / 47.1, SPLIT 5 — 23.2 / 37.2.
