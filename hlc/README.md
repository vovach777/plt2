# hlc — HALIC-класс на базе PALIC-1

Один цветовой трансформ (наш RCT = режим 0 HALIC), независимые тайлы 256×256, предиктор на плоскость-тайл
(MED, `(2(a+b)−c)/3`, `(a+b+1)>>1`, без предсказания), полный zigzag-алфавит, одна таблица FSE на плоскость-тайл
(байтовый FSE, если всё < 256, иначе FSE-U16). Декодер как у HALIC: FSE пишет прямо в буфер тайла, предиктор
восстанавливает плоскость на месте, обратный RCT — SSSE3 по 16 пикселей сразу в RGB. Тайлы независимы → `-t N` потоков.

```
hlc c in.ppm out.hlc [-t N]     hlc d in.hlc out.ppm [-t N]     hlc bench [-t N] a.ppm ...
```
