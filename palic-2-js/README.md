# palic-2-js

Текстовый вид [palic-2](../palic-2). Это не бинарный файл. Раскладка та же: тайл 288, `off = 2`, `L` считается по символам сверху и не пишется, RCT, MED, `wrap8` у Y и `wrap9` у U/V, зигзаг, блоки по 16 символов через строку. У плоскости восемь корзин `L0..L7` и маски. Символ 511 при `L = 0` у хромы — обычный символ алфавита 512.

Node.js 18+, зависимостей нет.

```bash
node pln-text.js
```

Печатает `PLN2-TXT` синтетики 8×8 (`R = x·32`, `G = y·32`, `B = 128`) и проверяет, что декодер возвращает те же числа.

Из кода: `render(rgb, w, h)` — числа как есть, `renderTxt` — прогоны, `encodeRuns` / `decodeRuns` — одна корзина после разложения. Сюда же подставляется другой энтропийный кодер.

## PLN2

```text
PLN2
W H
4 13 22
L0 -
L1 1 1 4
M 0 0
```

Строка 1 — имя, строка 2 — размер картинки. Дальше индекс: номера строк, где в этом файле начинаются Y, U и V, через пробел. Тайлы одного ряда картинки стоят на одной строке индекса и разделены табом. Размер тайла из сетки, в файл не пишется:

```text
nx = (W + 287) / 288
ny = (H + 287) / 288
```

Потом плоскости по порядку Y, U, V. У каждой восемь строк `L0`…`L7` (старшие символы `z >> L`, десятичные) и строка `M` (маски, по одному слову на бит блока). Пусто — `-`.

## Runlen, бинарь

Те же корзины, но упакованы ниблами, по два символа в байт. Файл `RL02` или `RL01`.

| Байт | Смысл |
|---|---|
| два нибла `0..E` | два символа. 84 % прогонов имеют длину 1, отдельное поле длины им только мешало |
| `F0` и два нибла | прогон нулей длиной 4..255 |
| `F1` и четыре нибла | один символ больше 14 |

Перед ниблами — varint числа символов, хвостовой нибл дополнения не читается.

Эталон «текст → бинарь» — `bzip2 -9` этого числового текста, не palic-2. palic-2 жмёт пиксели своим кодером. Любой эксперимент на корзинах сравнивается с bz2 того же текста. Рейтинг строится по цвету, серый только для справки.

Rice (`RC02` / `RC01`) — адаптивный код Райса на тех же корзинах. `k` — это `floor(log2)` среднего последних трёх символов. Пока трёх нет, среднее считается по тем, что уже есть. В начале `k = 0`. Парабола пробовалась и проиграла этому среднему.
