# llrans — PALIC-1 без контекстов, по трём плоскостям

RCT (R−G, B−G, Y = G + (R−G + B−G)>>2; SIMD-блоки по 16 px, хвост внахлёст) → MED → zigzag →
символ = bit_width(zz) (A10: 0..9) + (s−1) сырых бит мантиссы → полустатика: гистограмма на окно 2^w символов
(упакована как в PALIC-1) → 4-канальный rANS64 (ренорм 32 бита), сырые биты кладутся в состояние rANS.
Состояния переходят между окнами (один flush на плоскость). Декодер без деления, поиск символа — 2×XMM + popcnt.

```
cmake -B build && cmake --build build --config Release      # -DLLR_ARCH=ivybridge|native|... (cl.exe: AVX|AVX2)
llrans c in.ppm out.lrn [-w 12..15] [-t 1|3]     # -t 3: по потоку на плоскость
llrans d in.lrn out.ppm [-t 1|3]
llrans bench [-w N] [-t T] a.ppm b.ppm ...
```
Исправления: `main.cpp` (p-conv) — хвостовой блок писался в плоскости без сдвига (`n*16` вместо `n*16 − offset/3`):
на ширинах, не кратных 16, хвост плоскостей был сдвинут; минимум ширины 48 → 16.
`convert_from_plannar_line_16to8_48` в `rgb.hpp` сломана (байты 0..31 неверны при любой перестановке аргументов) —
в llrans не используется, обратное RCT + перемежение RGB написано заново на SSSE3 (`irct16`).

`avx2.h` (амальгама SIMDe) общий с PLT2 — лежит уровнем выше. Сборка: `cmake -S palic-1 -B build-p1`.
