# PLT2 — PALIC-tiny v2

Lossless RGB. RCT → MED → контекст (корпусный кластер 64 на компоненту [× Enb]) → алфавит A31 (PALIC-2) или A15 →
буква: адаптивная (или статическая, `-x`) CDF + range coder; младшие биты класса (bypass): битовый поток.

## Устройство
- **Range coder с гибридным переносом.** low 64 / range 32, ренорм байтами на 2^24, модель 2^15. Перенос гасится в
  4 отложенных байтах внутри `low`; если после сдвига все 4 = 0xFF, range обрезается до `2^32 − low_окна`
  (гильотина Субботина) → **каждый выданный байт окончательный**. Декодер ведёт `low` и повторяет обрезку.
- **Один буфер на полосу, 4 чередующихся потока:** range Y, range U, range V и общий bypass всех трёх компонент.
  Резервирование слотов: range-кодер берёт 4 байта на старте и 1 на сдвиг; битовый писатель берёт 8-байтовое слово,
  когда в него ложится **первый** бит. Декодер резервирует в те же моменты. Буфер сразу окончательный, склейки нет.
- **Полосы:** N = W/512 по умолчанию или `-s N`; ⌊W/64⌋ блоков по 64 px раздаются поровну, хвост — последней.
  Полосы независимы → потоки ОС / Web Workers. Начала полос кратны 64 px (RGB совпадает с SIMD-блоками).
- **Память O(ширина):** RCT построчно в кольца из 2 строк, декодер пишет RGB сразу.
- **SIMD:** AVX-512BW, AVX2, SSE4.1 (Nehalem…Ivy Bridge), встроенный SIMDe для core2, скаляр. Поток одинаковый.
- Альтернативные раскладки (несколько буферов на полосу, bypass внутри RC) — в `archive/`, финальный декодер о них не знает.
- `palic-1/` — llrans: PALIC-1 без контекстов (zigzag + bit_width, полустатика, 4×rANS) — точка отсчёта по скорости.

**Файл:** `PLT2 | u32 W | u32 H | u8 model | u8 флаги (b0 A15, b1 статика, b2 свои таблицы) | u8 раскладка = 3 |
u8 полосы (0 = W/512) | [u32 отпечаток таблиц, если b2] | u32 len[N] | полосы`.

## Сборка и запуск
```
cmake -B build && cmake --build build --config Release        # -march=native (clang-cl/gcc/clang), /QxHost (icx)
cmake -B build -DPLT_ARCH=ivybridge                            # явный ISA для gcc/clang/clang-cl
cmake -B build -DPLT_ARCH=AVX                                  # cl.exe: AVX | AVX2 | AVX512 (без него SSE2 → SIMDe)
```
Путь SIMD выбирается по ISA цели, поток одинаковый: AVX-512BW → AVX2 → **SSE4.1** (Nehalem…Ivy Bridge, родные XMM) →
встроенный SIMDe `avx2.h` (core2 и старше) → скаляр (`-DPLT_SCALAR=ON`). Внешний SIMDe не нужен; `-DPLT_SIMDE=1|2
-I<simde>` (эмуляция AVX2/AVX-512 из полного SIMDe) оставлен для экспериментов.
```
plt2 c in.ppm out.plt [-t N] [-m 0|1] [-a 31|15] [-s strips] [-x] [-T tables.pltt]
plt2 d in.plt out.ppm [-t N] [-T tables.pltt]
plt2 bench [опции] [-r R] [-csv f] (ppm | папка)...
plt2 train (ppm | папка)... -o my.pltt [-H my.h] [-p 32] [-t N]
```
`-m 1` кластер × Enb (по умолчанию), `-m 0` только кластер; `-a 15` алфавит A15; `-x` статика (CDF корпуса без
обновления); `-T` свои стартовые/статические таблицы (из `train`), отпечаток в файле — декодер с чужими таблицами
отказывается. Отладка: `-DPLT_DEBUG` (счётчик вылетевших переносов), `-DPLT_STRESS` (обрезка чаще, проверка).

хвост битового слова, округление range ~2·10⁻⁴ бит/символ). Гильотина на реальных данных не срабатывает.

## WASM / браузер
`wasm/` — автономный декодер (без libc), SIMD128 и скаляр, `run.mjs` для Node. `web/` — страница с canvas,
Web Worker на полосу, экспорт полосы сразу в RGBA. Headless Chromium, 4000×3000: 1 воркер 40 MB/s,
2 воркера и `-s 2` — 79 MB/s (×1.95); статика `-x` в WASM SIMD128 +57%.

## Обучение таблиц
`plt2 train` считает буквы по (компонента, кластер × Enb) для обоих алфавитов, квантует в 2^15 (мин. частота 2),
редкие контексты подтягивает к вшитой таблице (`-p`). Важно прежде всего для статики; адаптивной модели старт
почти безразличен (±0.3%). На 13 разнородных картинках не обобщается — нужен корпус (CLIC).

## gen/
`gen2.py` (вшитые таблицы из jointstats CLIC train), `design_a15.py` (подбор A15). Нужны корпусные `jointstats.npz`,
`clusters_64.npz` и `invcommon.py`.
